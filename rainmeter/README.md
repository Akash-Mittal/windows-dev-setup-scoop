# Rainmeter skins

`trump-skins` contains:

* `world_clock.ini`: world clock.
* `HalfHourReminder.ini`: a reminder every 30 minutes.

## `copy.skins.ps1`

Copies `trump-skins` into `Documents\Rainmeter\Skins`. Runs from `setup.ps1` (`setup_scripts`, "Rainmeter skins").
Rainmeter itself starts at login (`startup_apps`, "Rainmeter").

```powershell
.\copy.skins.ps1
```

Then in Rainmeter, open **Manage**, expand `trump-skins`, select a skin and click **Load**.
